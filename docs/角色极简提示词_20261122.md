# 角色极简提示词

每组使用角色名、作品名和 2–3 个外观特征。动作、画质和场景可独立叠加。已在 REED Anima v1.4 用同一种子逐人实测。[逐图评语与原图](../examples/角色实测/角色极简词实测.html)。

安比取狡兔屋版本，席德取驾驶员本人，镜流分为眼罩版与露眼版，芙宁娜取短发造型。桐谷直叶取现实形象，莉法取 ALO 形象；小黑塔取人偶，大黑塔取本体。
